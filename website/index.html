Low-level abstraction layer over platform and graphics APIs

PAL is a thin, low-level, explicit, cross-platform abstraction layer in C over graphics and platform APIs. PAL exposes capabilities allowing applications to choose drivers, adapters etc based on needs and usage.

PAL is modular and extensible. Its modules (systems) can be used independently or used with other libraries or native APIs. The modules can also be used together through explicit interfaces. PAL supports custom event queues, custom memory allocators and custom graphics backends.

PAL uses a stateless design. This allows total transparency and the ability to use native APIs directly with PAL without any issues or stale data. Queries return actual runtime states which allows both PAL and the application write and read the same data at runtime.

PAL supports Windows, Linux, Vulkan and D3D12. Both Wayland and X11 are supported on Linux.

PAL is released under the zlib/libpng license.

Modules
  • Core Defines the types, constants and functions of the module. The module provides result codes, memoryallocation, logging, timing, shared library loading and value packing utilities.
  • Event Defines the types, constants and functions of the event module. The module provides the event driver, which delivers events to an event callback or an event queue according to the dispatch mode of each event type.
  • Video Defines the types, constants and functions of the video module. The module manages windows, monitors, cursors and icons, and reports keyboard and mouse input state.
  • Graphics Defines the types, constants and functions of the graphics module. The module manages devices, swapchains, images, buffers, pipelines, descriptors, etc.
  • OpenGL Defines the types, constants and functions of the OpenGL module. The module creates and manages OpenGL contexts and framebuffer configurations for native windows.
  • Thread Defines the types, constants and functions of the thread module. The module provides threads, thread-local storage (TLS), mutexes and condition variables.
  • System Defines the types, constants and functions of the system module. The module provides information about the CPU and the platform the application runs on.

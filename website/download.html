Source

This package contains the source code with the build files and available scripts, tools, tests, documentation and the website source files. This is the recommended download to use for all supported platforms and compilers. Any C99 that conforms to the PAL ABI can be built with it.

Prebuilt binaries are only available for windows. Linux and other platforms must build from source by downloading the source package.

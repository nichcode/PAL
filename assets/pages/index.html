Low-level abstraction layer over platform and graphics APIs

PAL is a thin, explicit, cross-platform abstraction layer in C. It doesn't hide the native APIs; it gives you one consistent way to reach them, and lets your application choose the drivers, adapters and backends that fit its needs.

Modules
  • Core Result codes, memory allocation, logging, timing, shared library loading and value packing utilities.
  • Event The event driver, which delivers events to an event callback or an event queue according to the dispatch mode of each event type.
  • Video Windows, monitors, cursors and icons, plus keyboard and mouse input state.
  • Graphics Devices, swapchains, images, buffers, pipelines, descriptors and more.
  • OpenGL OpenGL contexts and framebuffer configurations for native windows.
  • Thread Threads, thread-local storage (TLS), mutexes and condition variables.
  • System Information about the CPU and the platform the application runs on.

Modular

Use any module on its own, next to other libraries or native APIs, or together through explicit interfaces. Custom event queues, memory allocators and graphics backends are supported.

Stateless

PAL keeps no hidden copy of runtime state. Queries return the actual state, so you can mix PAL with native APIs without stale data.

Explicit

PAL exposes capabilities instead of deciding for you. Your application picks drivers and adapters based on what it needs.

Cross-platform

Windows and Linux (Wayland and X11), with Vulkan, D3D12 and OpenGL.
